# CLAUDE.md

Jack's desktop to-do widget (Python + tkinter, no packages). The README covers what it does and its commands.

## Theme (W1, shared with the usage widget)

- Ground: near-black `#0b0e15`; each to-do on a card one shade lighter, its top edge lighter as if catching the light.
- Colour logic: colours mean something. Each project has its own colour; the indigo accent (`#8b7cfa`) is for actions and focus. No colour of the day.
- Type: Hanken Grotesk (bundled in `fonts/`).
- Shapes: rounded cards and tick boxes; Windows 11 rounded corners.
- Elements: A (dark ground with light), B (colours that mean something).
